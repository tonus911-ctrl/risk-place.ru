Насколько зрелая у вас система управления рисками?

Тринадцать вопросов по пяти уровням зрелости, логика ГОСТ Р 70350 «Оценивание качества менеджмента риска организации». Результат сразу на экране: уровень, профиль по девяти областям, три главных пробела и первый шаг по каждому.

Отвечайте по фактам, которые можно показать документом, протоколом или расчетом, а не по намерениям. Если данных нет, выбирайте «затрудняюсь ответить»: результат от этого только точнее.
