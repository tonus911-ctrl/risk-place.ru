# risk-place.ru

Сайт практики управления рисками. Программы и тренинги по отраслям и функциям,
дашборд рисков проектов, консалтинг и корпоративная методология.

## Что внутри

- `index.html` — главная
- `pageN/` — 14 программ, каталог, услуги, статьи, политика конфиденциальности.
  Адреса сохранены со старого сайта, чтобы не потерять индексацию в Яндексе.
- `dashboard/`, `o-nas/` — новые разделы на читаемых адресах
- `assets/site.css` — единый файл стилей на весь сайт
- `sitemap.xml`, `robots.txt`, `404.html`

## Как правится

Страницы программ, каталога, услуг и статей собираются генератором.
Он лежит в проекте: `11 - Risk place.ru/11-5 Generator`.
Правка руками в этом репозитории будет затерта при следующей сборке —
меняем данные в генераторе и пересобираем.

Страницы вне генератора: `index.html`, `o-nas/`, `404.html`.
